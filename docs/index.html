Questspector is a 3rd party tool that takes character data exported by the Fallen London Sheetifier browser extension and uses it to generate a rough summary of your character's current progress in the game's storylines. Just upload you CSV file below to begin.

Note: The tool is incomplete. At the moment the bulk of the documented quests are found in London during the early and mid game.

Summary generation takes place client side within your browser. Your file won't leave your device.

Quests don't render until character data has been uploaded. Head to the UPLOAD tab to get started.

Note: This tool is currently in beta. The quest list is incomplete and almost certainly riddled with bugs and typos.

I'm seeing an error

That shouldn't be happening. See below for information on how to report an issue.

A quest state is wrong / giving incorrect advice / has a typo.

Another reportable issue. See below.

Quest documentation is difficult since there isn't a way to easily take a character through that specific narrative beat to confirm what the player will be seeing. Mistakes are inevitable and spreadsheet programs aren't known for catching the mistakes of traitorous fingers.

A storyline is missing

This is to be expected. There's a list of known missing storylines at the bottom of this page. If you don't see it there, it might be worth reporting as it's been easy to overlook the game's smaller and more obscure stories.

Note that not everything in the game counts as a story. Some things are just activites. A good marker for whether something counts as a story is if there's a quality that tracks it in the Stories section of your Myself page and it isn't repeatable.

How do I report an issue?

The most reliable way is to create an issue on the Questspector Github. Before creating your issue, please do a quick search to see if it has already been reported. Your issue should include:

  • The information in the box at the top of this page.
  • A description of the problem.
  • A screenshot of the problem.
  • The CSV file you used when you encountered it if applicable and if you're comfortable sharing it.
